How H.E.R.D. works.

HERD models protein immunogenicity as a host-dependent prediction problem rather than assigning a single host-agnostic score to every antigen.

Read the full tutorial ›
01

Host-resolved data

Protein-level immunogenicity datasets are resolved by host species. Core datasets combine manually curated experimental evidence with B-cell records mined from IEDB, while negatives are sampled from the same source taxa and matched by sequence length after homologous positives are removed.

CURATION · IEDB · MATCHED NEGATIVES
02

Protein representation

Each protein is encoded with the 650M-parameter ESM-2 protein language model. Final-layer residue embeddings are mean-pooled into a 1,280-dimensional representation used as input for downstream prediction.

ESM-2 · 1,280D EMBEDDINGS
03

Host-aware network

The integrated model uses a shared neural-network trunk followed by a dedicated sigmoid output head for each host. Joint training lets hosts share cross-species immunogenicity signal while retaining host-specific decision functions.

SHARED TRUNK · HOST-SPECIFIC HEADS
04

Validation

Performance is estimated with homology-aware nested cross-validation so homologous proteins cannot leak across folds. Leave-one-pathogen-out evaluation additionally tests transfer to antigen repertoires from previously unseen pathogen genera.

NESTED CV · HOMOLOGY-AWARE · LOPO
